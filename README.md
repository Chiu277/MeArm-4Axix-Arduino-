# MeArm-4Axix-Arduino
本專題結合工程設計流程(EDP)，採用「專題式學習」（Project-Based Learning, PBL）模式，使用 Arduino Uno R3 開發板、小型伺服馬達、雙軸搖桿擴充模組等硬體材料，開發一台基於 MeArm 四連桿機構形式的四軸機械手臂。專題貫穿工程設計流程，從定義問題、研究規劃、設計實作、測試評估到反思優化等步驟，嘗試解決機械設計、電子控制與軟體程式編寫的整合性挑戰。
